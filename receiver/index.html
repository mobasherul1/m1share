How downloading works ▾

Your name, then the code check. You type your name and tap Save name — the name is sent to the sender’s page, and you appear in the sender’s Live users list as active while you are on the share. The page then checks whether the sender has a login code active: if they do, you enter the code before the files open — a wrong code shows “Kindly get the code form sender”; if they don’t, you just tap Open files.

Blocked by the sender. The sender can block you from their Live users list at any time. If you are already in the open folder, you are logged straight out to the login-code section and shown a notice that you are blocked. While you are blocked, the files stay closed — even if you enter the login code, they won’t open. Ask the sender to unblock you.

Ticking. Every file and folder has a tick box. Tick a folder and everything inside it is ticked; untick one file inside and the folder shows a part-ticked mark. Only ticked files can be downloaded.

Download ticked. Only the ticked files download, one by one, in order: files ticked in the main folder first, then the ticked files inside sub-folders — each one as itself, with its folder path shown in the preview.

Download all files. Every file in the share downloads, one by one, in the same order — main folder files first, then sub-folder files. Files inside sub-folders download as themselves too. There is no ZIP option: zipping would put extra load on the sender’s PC.

Stay on this Wi-Fi. Downloads come straight from the sender’s PC over your router, not the internet. If a download stops, the sender may have turned sharing off or closed M1 Share — ask them to turn it on again, then try once more. Big files resume where they stopped when your browser supports it.
