      How receivers connect Four steps on any phone, tablet or PC on the same Wi-Fi ▾

      1. Same Wi-Fi. The receiver joins the same Wi-Fi / router as this PC.

      2. Open the link. They open http://… in any browser — no app to install.

      3. Save a name. Their name shows up in the Live user checker above, so you know who is in.

      4. Code (if set). They enter the login code above, then tick what they want and download — each file arrives as itself, main-folder files first, then sub-folder files. There is no ZIP.
