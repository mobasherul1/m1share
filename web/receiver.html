How downloading works ▾

Stay on this Wi-Fi. Downloads come straight from the sender’s PC over your router, not the internet. If a download stops, the sender may have closed the share or switched sharing off — ask them.

Ticking. Every file and folder has a tick box. Tick a folder and everything inside it is ticked; untick one file inside and the folder shows a part-ticked mark. Only ticked files are sent to your downloads.

Download ticked. Only the ticked files download, one by one — files in the main folder first, then the ticked files inside sub-folders — each one as itself.

Download all files. Every file in the share downloads, one by one, in the same order. There is no ZIP option: your browser saves each file itself.

One download at a time. Your browser asks for each file in turn. If it asks “allow multiple downloads?”, choose Allow.
